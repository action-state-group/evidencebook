- `Book.RequestSentWithCommitment` records a sent request as `RequestSent` does and also keeps a JSON object the requester held from the responder when it asked (such as the responder's advertised commitment) as the optional `commitment` member of the `evidence_request` statement (`RequestStatement.Commitment`). The book never reads or checks it. A record without the member reads as before, and a reader that does not know the member ignores it. Rust has the same as `ask::request_sent_with_commitment` (Mesh-LLM/capsules-plugin#368, row B3).
