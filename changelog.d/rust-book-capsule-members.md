- Rust book entries carry Capsule members, as Go's `Entry.Members` does (#857). `BookEntry` gains `members` (further top-level members of the record's Capsule, by name; the Capsule's id and signature cover them, the header does not), so a struct-literal `BookEntry` must name it (`..BookEntry::new(..)` or `members: Default::default()`); `seal::seal_record_with_members` seals them, a base-profile name, `evidence_record_header`, a null value or a badly named member is refused as `ShelfError::Invalid`, and `SealedRecord::verify` reads them back. `Shelf::seal_sent` refuses an entry that sets `members` (its `members` argument is the standalone Capsule's, and the journal record's Capsule carries none). With no members every record id and vector is unchanged. The shared holder transcripts now replay in full: all 33 scenarios, byte for byte with Go.
