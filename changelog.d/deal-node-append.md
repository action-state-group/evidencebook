- `deal node append` and `deal node records` keep a node's own book on the deal profile's shelf (evidencebook#624): `append --book ID --type T --statement FILE [--subject-ref S] [--cite ID]... [--payload FILE]... [--once MEMBER]` seals one record as a producer claim under the profile's key, and `records --book ID [--type T]` lists a book's records oldest first with their statements. The record types are the node's own names. `--once MEMBER` seals nothing when the book already holds a record of that type with the same value for that statement member, so a repeat after an interrupted run neither doubles nor loses a record. A deal's book, a sale, the cadence and the journal are refused: only the deal verbs write them. The verbs run through the same session as every deal verb, so the store's mutation counter stays consistent.
