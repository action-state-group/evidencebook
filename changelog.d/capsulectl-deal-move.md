### Changed: `capsulectl-deal` moves into this repository (#610)

- The `capsulectl-deal` plugin (`capsulectl deal ...`: the deal verbs and a deal profile's SQLite store) moved here from evidencebook-deal with its commit history, to `capsulectl/cmd/capsulectl-deal`, `capsulectl/internal/deal`, `capsulectl/skills/deal` and `capsulectl/examples`. `capsulectl/` is now one module with two launchers, `capsulectl-book` and `capsulectl-deal`, built from one source tree, tested by one CI workflow (eight race shards and two plain shards of `capsulectl/scripts/test.sh`, the deal pages, portability, studio replay, presentation pass and interop jobs, and the nightly full-case race run) and released together: one `capsulectl/vX.Y.Z` tag publishes both launchers, `deal-view-` and `deal-skill-` archives, and one `SHA256SUMS`, with the asset names evidencebook-deal used. Neither launcher links the other's package, so each keeps its own commands, hooks and wording, and `capsulectl` stays core-only. The deal changelog up to the move is `capsulectl/CHANGELOG-deal.md`; its issue and PR numbers are evidencebook-deal's.
- `capsulectl/go.mod` requires capsule-cli `v0.1.0-rc46` (was rc45): the first release that hands `SetDealV1ReportVerifier` the x-deal-v1 extension. The core-only `capsulectl verify` still reports the x-deal-v1 report rule `NOT_CHECKED`; `capsulectl-deal verify --bundle` runs it.
- A deal release's notes link is now this repository's `capsulectl/vX.Y.Z` release, and the release workflow refuses a version a shared copy's producer string cannot carry.
