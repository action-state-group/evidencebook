- `deal node checkpoint` and `deal node bundle` give a node's own book on the deal profile's shelf its newest checkpoint and Evidence Bundles (evidencebook#624). `deal node checkpoint --book ID [--out FILE]` prints the book's newest checkpoint (its id, the records it covers, its root and signing key), cut now when the book grew, `--out` writes the signed statement (COSE) to a new file for a host to submit to its witness, and `--list` prints every checkpoint the book holds with whether a witnessed cadence tick covers it and how (`cadence_extent`). `deal node bundle --book ID --record ID --out FILE [--at CHECKPOINT_ID] [--disclose] [--witness-receipt FILE --witness-directory FILE]` writes an `evidence-bundle/v2` that proves the record is in the book under a checkpoint (the newest by default), and verifies it before writing it to a new file. By default the bundle carries the record and what it commits and withholds the headers and payloads of the records it discloses, each by its digest; `--disclose` reveals the header of the record and of the records it links to (one hop, whatever the link type), and their payloads, and the book commits a disclosure record naming what was shown, so its own history says so; the book has then grown, so the next default checkpoint is new and a witnessed tick carries it only as a later checkpoint of the book (the cadence chain travels as `part`), and `--at` with a checkpoint `--list` shows as `all` gives the tick's own. The interval runs from the earliest record the bundle selects to the checkpoint. A `--book` the shelf does not hold is an input error, not a new empty log. A witness receipt for the `--at` checkpoint is carried only when it verifies under the witness directory named, and then no bundle is written otherwise; when a witnessed cadence tick carries the checkpoint, the cadence chain travels in the `x-cadence-witness/v0` extension. The witness itself is the host's transport: the host submits the statement and gives the receipt back. A bundle shows that the record is in the book at that position, not that its content is true. A deal's book, the cadence and the journal are refused, as for `deal node append`.
