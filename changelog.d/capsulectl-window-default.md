### Changed: a new `capsulectl-book` store is split by month windows (#805)

- `store init` on a book profile with no store now creates a windowed store with month windows (calendar months in UTC, fixed for good) and prints `capsulectl: window: month (calendar months, UTC), fixed for this store` on stderr. `book window init --period day|week|quarter|year` fixes another window instead, and `--period none` one JSONL book for the store's whole history. A reproduced scratch book (`SOURCE_DATE_EPOCH`) and a profile whose pre-book cll.jsonl still holds entries stay JSONL; an existing store is unchanged.
- The book plugin declares a windowed store's window logs to the core (capsule-cli's `OwnsLogID`, capsule-cli#622), so `cll checkpoint status`, `cll checkpoint publish` and `cll proof verify` read a window log's checkpoints; `book window publish` still delivers closed windows' final checkpoints.
