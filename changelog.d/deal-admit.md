### Added: `capsulectl deal admit`, sealing capsule-engine's admission decision for an x-deal-v1 deal (#626)

- `deal admit --deal ID --input FILE` takes the output of `capsule-engine admission evaluate --admit FILE` and seals its admit body, exactly as printed, in the profile's journal as an x-deal-v1 `admit` record. It then prints the record's digest. Before this, no command wrote the admit that `deal agree` must cite, so an x-deal-v1 deal could not be agreed outside the tests. The refusal follows the engine's `admits_deal` (an ASK, a NO, or a LIMIT whose tier does not hold the deal) and says to answer the asks in capsule-engine. A body that is not exactly the engine's, or that disagrees with the verdict or pack it came with, is refused. Each deal has one admission decision: a second one is refused, and a re-run prints the same digest. The record carries no deal id (x-deal-v1 PROFILE §3), so the plugin keeps the binding itself.
- `deal agree` cites the deal's own admission decision when `--admit` is left out. It refuses an `--admit` that `deal admit` sealed for another deal, or that is not the deal's own.
