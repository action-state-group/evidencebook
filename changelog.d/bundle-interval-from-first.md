- `BundleRequest.IntervalFromFirst` starts a bundle's interval at the book's first record (seq 1) whatever the selected set holds, so the interval proves the log from its first leaf to the anchor, as a standard_history handover's already does (evidencebook#624, for the Goose node's `deal node bundle`). By default the interval still starts at the lowest sequence number the selected set holds. It changes no record disclosed, only how much of the log the interval proves.
