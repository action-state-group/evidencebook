### Changed: capsulectl's book and deal skills are one agent skill on five verbs (#995)

- `capsulectl/skills/capsulectl-book` merged into `capsulectl/skills/deal`, which keeps its name and path, so `deal open --skill`, the install check and the `deal-skill-$V.tar.gz` release asset are unchanged; the asset now carries the book commands too. The skill teaches five verbs, check, record, ask, verify and show, in one table, "The five verbs", that maps each to an existing `deal`, `book` or core command; book commands run on a book profile, never the deal profile. No command changes.
- The commands outside the five are expert commands, kept with their instructions in the skill's references: `references/setup.md` (installing the plugin, creating the profile and store, moving a store to x-deal-v1, the materiality predicate, the checkpoint cadence and its network grant), `references/expert.md` (reading at the last checkpoint with `deal tick`, `deal settlement`, the window commands, `deal set-version`, the daily check of host actions with `deal audit-host`) and `references/book.md` (the book commands in full, with `book close`, `book result derived-inputs` and the window commands as expert commands). SKILL.md keeps the rule that setting up is the user's step, and names the setup reference as required reading before the first deal on a profile.
- The skill names Mesh's service card as an exception, not a second commerce card. The book skill's `AGENTS.md` copy is gone; `skills/deal/scripts/check-book-verbs.sh` and `run-book-demo.sh` replace its `check-skill.sh` and `run-scripted-demo.sh`.
