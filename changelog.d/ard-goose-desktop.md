- The ARD two-seller demo runs in Goose Desktop: `python/examples/ard-commerce/desktop_server.py` is a Goose extension with five tools (`ard_find_sellers`, `ard_show_history`, `ard_assess`, `ard_pick`, `ard_pay`) over the same run as `demo.py`, with `goose/open-windows.py`, which opens three Goose Desktop windows (Maya, Alder, Kestrel; one process, key set and data directory each). `demo.Run.settle` is split into `seal` and `pay_deal`, behaving as before. A `local` payment rail (`--rail local`, `ARD_RAIL=local`) pays between two local Lexe wallets with the separate `ln-pay-local` program; the Brattain and Shockley rail stays the default.
