- `deal node seal-model-call` seals one model call an agent made as an effect-boundary record of a node book (evidencebook#624): `--book ID --type T --provider P --model-id M --prompt FILE --completion FILE [--developer D] [--out FILE]`. The record is a Capsule signed in the process under the profile's key, whose effect is an inference completion that the runtime claims (`effect_attestation` `runtime_claimed`, nothing stronger) and whose `model_attestation` names the provider and model id. The prompt is kept as the record's payload and committed by digest; the completion is committed by digest only and never stored. `--out` writes the Capsule with its `signature` and `key_id`, as a verifier reads it, to a new file (never over an existing one).
